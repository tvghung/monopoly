# 08B evidence

> **HISTORICAL** — Raw reports behind [08B Phase B0 + B1](../08B_PHASE_B0_B1_IMPLEMENTATION.md) (2026-10-16). Generated by
> `scripts/perf/runBenchmark.mjs`, `scripts/perf/compareResults.mjs` and `scripts/perf/captureCompare.mjs`; see
> [scripts/perf/README.md](../../../scripts/perf/README.md). Screenshots are not committed (they are reproducible with the
> same command and bundle).

Machine: MSI Katana GF76 (i7-11800H), Chrome 155 on the Intel UHD Graphics iGPU, 1920×1080 at 144 Hz, devicePixelRatio 1, AC
power. This is **not** the Phase A reference laptop; the two sets of numbers are never merged. Every `results.json` carries its
own environment block (commit, options, GPU renderer, viewport, drawing buffer, measured refresh rate).

| File | What it is |
| --- | --- |
| `b0-baseline_*.json` | Baseline: bundle built from the clean B0 commit `3790870` (`balanced-cap60` = all scenarios; `low-high-cap60` = Low and High, all scenarios; `balanced-cap240` = no FPS cap; `balanced-diag-off` = production-style scene tree; `balanced-lite-diag-off` = passive observers only, used to bound the probe's overhead; `soak-diag-off` = 30-replay soak with diagnostics off) |
| `after-b1_*.json` | The same runs on the bundle built from the clean B1 commit `fedbf49`; `long-soak-90` is a 90-replay soak, diagnostics off |
| `compare_*.md` | `compareResults.mjs` tables for each pair of reports |
| `visual_gpu_b0-vs-b1.json` | Pixel comparison of 19 settled states, B0 against B1 bundle, same browser and GPU, 1280×720 |
| `visual_gpu_b0-vs-b0-dice.json`, `visual_gpu_b1-vs-b1-dice.json` | The same capture of one bundle against itself, for the one state (dice settled) that is not deterministic between captures |
| `motion_impact_b0-vs-b1.json` | Mid-animation tile-impact comparison (frozen-clock probe), cross-bundle, determinism control and animation-visible counts |
| `lifecycle_b0-bundle.json`, `lifecycle_b1-bundle.json`, `lifecycle_b1-dev-server-strictmode.json` | Live scene-graph ownership facts (distinct materials per effect, effects drawn, tier cycle, context loss, console messages) for the B0 bundle, the B1 bundle and the B1 code on the React development server |
| `visual_swiftshader_*.json` | The same three comparisons under software WebGL (SwiftShader) for eight states (cross-bundle) and for the dice state (each bundle against itself) |

Reading notes: a `workingTreeDirty: true` flag in a baseline report means uncommitted B1 edits were in the working tree while
that stage ran; its bundle had been built beforehand from the clean B0 commit and does not contain them. The baseline
`soak-diag-off` run executed after the B1 commit with the B0 bundle. `balanced-lite-diag-off` has no frame data on purpose (its
wrappers are not installed); only its long-animation-frame figures are meaningful.
