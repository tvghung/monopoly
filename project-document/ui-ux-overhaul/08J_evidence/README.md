# B5 evidence

All captures compare the unchanged B4 head `79fff0e` with the selected B5 build in the same headed Chrome 155 session on Intel UHD 0x9B41. Each `before/` and `after/` pair uses the same fixture, camera, viewport and device scale. `desktop/` is 1280×720 at DPR 1; `dpr125/` is 1280×720 at DPR 1.25; `small/` is 896×414 at DPR 1.25. The accompanying `visual-*.json` files contain every attempted state's numeric image difference and page errors. Differing pixels are expected because B5 changes render scale, shading and High MSAA.

`baseline.json` and `final.json` are the full deterministic 18-cell benchmark suites. `dpr-table.json`, `selective-ibl.json` and `balanced-sharpness.json` are intermediate controlled experiments. `soak.json` holds the selected 30-replay Low/Balanced resource series; `warmup-summary.json` and `lifecycle.json` cover shader and object ownership. `motion-cross.json` records the expected non-comparability of changed pixel buffers/shading; `motion-self.json` is the selected-build control. `real-session-*.json` contains three observational, random two-browser game rolls and the completed flow steps. The benchmark's own environment metadata records hardware, browser, device ratio, buffer size, cap, fixture, replay count and GPU timer support. Comparisons with a changed internal drawing buffer are intentionally flagged by `perf:compare`; see [08J](../08J_PHASE_B5_IMPLEMENTATION.md#measurement-protocol-and-comparability).
